# Kubernetes DevSecOps Lab

A hands-on DevOps / Platform Engineering / DevSecOps portfolio project demonstrating Docker, Docker Compose, GitHub Actions, GitHub Container Registry, Kubernetes, Helm, Argo CD GitOps, Trivy security scanning, SBOM generation, PostgreSQL, Prometheus, and Grafana.

## Purpose

This project is a production-inspired local lab designed for learning and portfolio development.

It demonstrates how a containerized application can move from source code to CI, security scanning, image publishing, Kubernetes deployment, GitOps reconciliation, and observability.

## Planned Stack

- Node.js backend
- HTML / JavaScript frontend
- PostgreSQL
- Docker and Docker Compose
- GitHub Actions
- GitHub Container Registry
- Local Kubernetes with kind
- Helm
- Argo CD
- Trivy
- SBOM generation
- Prometheus
- Grafana
